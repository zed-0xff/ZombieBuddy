[h1]ZombieBuddy 临时修复 · 性能优化 · 内置自动汉化 / Temporary Fix · Performance · Auto CN/EN[/h1]

[h2]内置自动汉化 / Built-in automatic CN/EN localization[/h2]
[b]1.1.0 已把原 ZombieBuddyCN 的汉化和中文字体直接合并进 ZombieBuddy.jar，无需另外启用汉化 Mod。[/b]
游戏语言为 CN 时中文，EN 时英文；读取启动前 options.ini 并跟随实际游戏语言变化。审批窗口、签名说明、加载提示、水印、原设置界面和重启提示自动切换。Swing 子进程继承游戏语言。仍启用的旧 cn.zbcn Java 汉化入口会自动跳过，避免固定中文转换重复覆盖。
[b]Version 1.1.0 embeds the previous ZombieBuddyCN translations and Chinese font inside ZombieBuddy.jar. No separate translation mod needs to be enabled.[/b]
CN game language uses Simplified Chinese; EN and other languages keep original English. Approval UI, loading text, watermark, original settings and restart notices follow the game language. Standalone Swing approvals inherit the parent language. The superseded cn.zbcn Java package is skipped automatically.
审批 Boolean、y/n、模组 ID、哈希、签名和协议字段不翻译。TinyFD 系统原生按钮仍按系统语言显示。The approval values and protocol remain unchanged; TinyFD system-native buttons still use the OS language.

[h2]中文安装步骤[/h2]
[list]
[*]完整退出游戏、Coop 与服务器。Steam → 管理 → 浏览本地文件，确认实际启动的游戏目录。
[*]打开本补丁下载目录：steamapps/workshop/content/108600/本补丁工坊ID/mods/ZombieBuddyOptimized/42.21/。
[*]备份游戏目录旧 ZombieBuddy.jar，把本补丁同名 JAR 复制到该游戏目录。保留原 zbNative.dll 和原启动方式，不要覆盖原工坊里的 ZombieBuddy.jar。
[*][b]作者列表 authors.json 也必须替换：[/b]备份后，把本补丁 authors.json 原样复制到原模组目录 steamapps/workshop/content/108600/3619862853/mods/ZombieBuddy/authors.json（与 libs、41、42 同级）。
[*]同时把 authors.json 复制到实际作者缓存：默认 %USERPROFILE%/.zombie_buddy/authors.json；使用 config_dir 参数时，复制到该配置目录。运行时联网会刷新，离线时使用缓存，所以这两处都更新。
[*]不要编辑、重排 JSON 或改变编码/换行。此文件包含上游官方签名，覆盖原始内容。
[*]若之前配置了 ZombieBuddySelectiveHooks.jar 的前置 Agent，请移除其启动参数。本版已合并功能，两版不可同时加载。
[*]正常启动并通过原 Java 模组审批。首次获准的新/更新模组会先等待；提示必须重启后确认退出，再完整启动游戏生效。建议保存审批决定。
[/list]

[h2]修复与优化 / Fixes and optimizations[/h2]
[list]
[*]修复 42.21 的 loadMods(ArrayList → List) 接口变化造成的“框架已启动但 Java 模组不加载”；保留旧 ArrayList 调用入口。
[*]每个模组只扫描自己的 JAR；按目标类筛选，减少无关类通知与重复转换。保留精确目标、通配和正则语义。
[*]新获准、更新、重新启用或停用已加载 Java 模组后，要求重启以使 hook 与当前启用列表一致。
[*]跳过停用的预加载项，处理默认/存档列表衔接；HTTP 初始化失败进入原回退流程。
[*]原审批、ZBS 签名、公钥、作者信任与封禁判定保留，不自动批准模组。
[*]Restores the List-based loader entry on 42.21 while preserving the legacy ArrayList API.
[*]Scans only the current mod JAR, filters unrelated class notifications, and removes duplicate retransformation. Wildcard and regex targets keep their meaning.
[*]Enforces a full restart when approved Java-mod selection changes; retains original approval, signature and ban checks.
[/list]

Based on stable 2.3.3; validated with 42.21, bundled Java 25 and the existing native Windows launcher. This does not automatically fix game-API incompatibilities inside other Java mods. No full-game startup speed percentage or complete multiplayer/mod-combination validation is claimed.
