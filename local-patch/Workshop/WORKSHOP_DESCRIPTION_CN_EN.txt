[h2]中文安装[/h2]
[list]
[*]完整退出游戏、Coop 和服务器。Steam → 管理 → 浏览本地文件，确认实际启动的游戏目录。
[*]本包文件位于 steamapps/workshop/content/108600/3810617983/mods/ZombieBuddyOptimized/42.21/。
[*]备份游戏目录旧 ZombieBuddy.jar，用本包同名 JAR 替换。保留 zbNative.dll 和原启动方式，不要覆盖原工坊 JAR。
[*][b]authors.json 也必须替换：[/b]备份后，将本包文件原样复制到 steamapps/workshop/content/108600/3619862853/mods/ZombieBuddy/authors.json（与 libs、41、42 同级）。
[*]同时复制到运行缓存：默认 %USERPROFILE%/.zombie_buddy/authors.json；使用 config_dir 时改用该配置目录。两处都更新，覆盖工坊文件与离线缓存。
[*]不要编辑或重新排版 authors.json，也不要改变编码/换行，官方签名覆盖原始内容。
[*]移除旧 ZombieBuddySelectiveHooks.jar 的启动参数。旧 cn.zbcn 汉化 Java 入口会自动跳过，无需另外启用汉化。
[*]照常审批 Java 模组，建议保存决定。提示必须重启时退出并重新启动后生效。
[/list]

[h2]English installation[/h2]
